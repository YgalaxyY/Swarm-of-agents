# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-02-28

### Added
- Enhanced Swarm Deployer v2.0 with strict context protocol
- Handoff mechanism for logged task transfer between agents
- Sequential thinking MCP server integration
- Enhanced memory system with structured Markdown files
- Role-specific SOPs for each agent type
- Automatic MCP server installation and configuration
- Improved error handling and logging
- Memory archive system for backup
- QA checklist integration

### Changed
- Complete rewrite of deployment script for better reliability
- Improved agent coordination protocols
- Enhanced memory structure with active_state.md as single source of truth
- Better integration with Windsurf/Roo Code IDEs

### Fixed
- Context loss issues between agent handoffs
- MCP server installation failures
- Memory corruption problems

## [1.0.0] - 2026-02-28

### Added
- Initial Agent Swarm framework
- Basic agent roles (Supervisor, Architect, Coder, Tester, Researcher)
- MCP server integration
- Memory system (.swarm_memory)
- Deployment automation
- Basic tools and scripts
- Documentation and README
